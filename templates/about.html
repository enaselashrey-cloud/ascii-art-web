About The Project

This project is a web-based ASCII Art generator that allows users to convert text into creative ASCII designs using different fonts.

How It Works

Users can enter text, choose a font style, and generate ASCII art instantly through a simple and interactive web interface.

Features

  • Multiple fonts (standard, shadow, thinkertoy)
  • Simple and clean user interface
  • Fast rendering using Go backend
  • Support for multi-line input

Technologies Used

  • Go (Backend)
  • HTML & CSS (Frontend)

Project Goal

The goal of this project is to practice building web servers in Go and creating interactive user interfaces.
